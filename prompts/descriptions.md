# Description generation prompt (Gemini — reference only)

The local description builder is used by default; this prompt documents
the style a Gemini rewrite should follow if one is added later:

- First line: the video's promise, in one sentence, using a keyword
  from the channel brief.
- Second paragraph: what the video covers, naming only topics that
  appear in the channel's real keyword list.
- Never invent timestamps, guests, links, sponsors, or claims.
- End with one subscribe call-to-action. Under 900 characters.
